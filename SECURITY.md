# Security Policy

## Supported Versions

AlgoHatch is currently pre-1.0. Security fixes are applied to the latest published version; older
versions are not maintained as separate release lines.

## Reporting A Vulnerability

Do not disclose a suspected vulnerability in a public issue. Once the repository is hosted on
GitHub, use its private vulnerability reporting feature when available. Until a private reporting
channel is configured, external vulnerability reports cannot be accepted safely.

Include the affected version, a minimal reproduction, the expected impact, and any known
workaround. Please allow time to confirm the report and prepare a coordinated fix before public
disclosure.
