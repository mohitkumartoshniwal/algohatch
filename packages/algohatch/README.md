# AlgoHatch

AlgoHatch is a TypeScript-first data structures and algorithms library built around practical
contracts, understandable implementations, shared correctness tests, and explicit engineering
trade-offs.

## Status

AlgoHatch is currently preparing its foundations and first data structure. The package is not yet
published and intentionally has no public data-structure exports.

The first planned implementation is `DynamicArray<T>` after the JavaScript storage and complexity
fundamentals are reviewed.

## Runtime

AlgoHatch targets Node.js 22 or newer and is distributed as an ECMAScript module.
